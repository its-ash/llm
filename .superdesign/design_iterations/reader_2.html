Attention Mechanisms Explained

Generated by GPT-Class Model 8 min read

Attention is the mechanism that allows a language model to decide, at every step of processing, which parts of the input deserve the most focus. Instead of compressing an entire sequence into a single fixed vector, attention lets the model look back across all tokens and weigh their relevance dynamically. This single idea, introduced in 2017, became the foundation for nearly every modern large language model.

Why Attention Was Needed

Earlier sequence models, such as recurrent neural networks, processed text one token at a time and carried forward a hidden state summarizing everything seen so far. This worked reasonably well for short sequences, but long documents caused the hidden state to lose information — a phenomenon often called the vanishing context problem. Attention solves this by giving the model direct, unmediated access to every previous token, no matter how far back it appeared.

Queries, Keys, and Values

Every token is projected into three vectors: a query, a key, and a value. The query represents what the current token is "looking for," the key represents what each other token "offers," and the value carries the actual content to be aggregated. Attention scores are computed by comparing a token's query against every other token's key, then using those scores to build a weighted sum of values. 

scores = (Q @ K.T) / sqrt(d_k)
weights = softmax(scores, dim=-1)
output  = weights @ V

Multi-Head Attention

Rather than computing a single attention pass, transformers run several attention "heads" in parallel, each with its own learned projections. This lets the model attend to different types of relationships simultaneously — one head might track subject-verb agreement, another might track coreference across paragraphs. The outputs of all heads are concatenated and projected back to the model's working dimension.

  • Each head learns an independent set of query, key, and value projections.
  • Heads are computed in parallel, keeping the operation efficient on modern hardware.
  • Combining heads gives the model a richer, multi-perspective representation per token.
  • Typical models use between 8 and 96 heads depending on scale.

Self-Attention vs. Cross-Attention

In self-attention, queries, keys, and values all come from the same sequence — this is how decoder-only models like most modern LLMs build context. In cross-attention, queries come from one sequence while keys and values come from another, which is common in encoder-decoder architectures such as translation systems, where the decoder attends over the encoder's representation of the source text.

The Cost of Attention

Standard attention compares every token to every other token, giving it quadratic complexity with respect to sequence length. This becomes expensive as context windows grow into the hundreds of thousands of tokens. Techniques such as sparse attention, sliding-window attention, and linear attention approximations have been developed to reduce this cost while preserving most of the quality benefits of full attention.

Key Takeaways

Attention gives transformers the ability to dynamically weigh relevant context regardless of distance in the sequence. Multi-head attention adds representational depth by letting the model track several relationship types at once. Understanding this mechanism is the single most useful step toward understanding how modern LLMs reason over long inputs.
