How Transformers Work

A structured walkthrough of the Transformer architecture that underlies most modern large language models — from raw tokens to predicted output.

Overview

The Transformer is a neural network architecture introduced in 2017 that replaced recurrence with a mechanism called self-attention. Instead of processing tokens one at a time in sequence, a Transformer looks at an entire sequence at once and learns which tokens should influence each other.

This parallelism is the main reason Transformers scale so well on modern hardware, and why they became the foundation for GPT, BERT, and nearly every large language model in production today.

Self-Attention, Briefly

For every token, the model computes three vectors: a Query, a Key, and a Value. The Query of one token is compared against the Keys of all other tokens to decide how much attention to pay to each of them.

  • Query (Q): what this token is looking for.
  • Key (K): what this token has to offer.
  • Value (V): the actual information passed along once attention is applied.
  • Multiple attention "heads" run in parallel, each learning a different kind of relationship (syntax, coreference, topic).
! Key Insight

Attention is not a fixed rule — it's learned. The same word can attend to completely different parts of a sentence depending on context, which is why Transformers handle ambiguity so well compared to older architectures.

Stacking Layers

A single attention block isn't enough. Real models stack dozens of identical layers, each refining the token representations a little further before passing them to the next.

Why It Matters

Because Transformers process sequences in parallel rather than step-by-step, training can be distributed efficiently across GPUs/TPUs. This is the key enabler behind scaling laws — bigger models trained on more data reliably get better, and Transformers are the architecture that made that scaling practical.
