Attention Mechanisms

Attention lets a model decide, for every output token, which parts of the input sequence deserve focus. Instead of compressing an entire sequence into one fixed vector, attention keeps every position accessible and lets the model weigh them dynamically.

Prerequisite check

This file assumes you've read tokenization.md and understand how raw text becomes token IDs before being embedded.

1. From embeddings to attention scores

Each token embedding is projected into three vectors: a query Q, a key K, and a value V. The similarity between a query and every key produces a raw attention score.

score(Q, K) = (Q · KT) / sqrt(d_k)

Dividing by sqrt(d_k) keeps the dot products from growing too large as dimensionality increases, which stabilizes gradients once the scores pass through softmax().

2. Softmax and weighted sums

The scores are normalized with softmax so they sum to 1 across the sequence, then used to compute a weighted average of the value vectors. This weighted sum becomes the new, context-aware representation of the token.

  • High attention weight means the token pulls strongly from that position's value vector.
  • Near-zero weight means that position is effectively ignored for this query.

Callout · Why it matters

Self-attention removed the sequential bottleneck of RNNs — every token can look at every other token in a single step, which is what made large-scale parallel training of transformers practical.

3. Multi-head attention

Rather than computing attention once, the model runs several attention "heads" in parallel, each with its own learned Q, K, V projections. Heads are concatenated and passed through an output projection W_o.
